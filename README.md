# YouTube Shorts Uploader

Information and policy pages for a privately operated YouTube Shorts publishing application, adapted from [Meta-Publicher](https://github.com/brajjan79/Meta-Publicher).

This repository contains documentation only; it does not include an uploader implementation.

- [Application information](docs/index.md)
- [Privacy Policy](docs/privacy.md)
- [Data Deletion Instructions](docs/data-deletion.md)
- [Terms of Service](docs/terms.md)

To serve these pages with GitHub Pages, configure the repository to deploy from the `/docs` folder on the appropriate branch. The pages retain the original Jekyll front matter and relative navigation links.
