# Data Deletion Instructions

YouTube Shorts Uploader is a private content-publishing application used only by its owner and authorized administrators.

## Revoke access

To stop YouTube Shorts Uploader from accessing a YouTube channel, open your [Google Account connections](https://myaccount.google.com/connections), select YouTube Shorts Uploader, and remove its access to your Google Account. See [Google's instructions for managing third-party connections](https://support.google.com/accounts/answer/13533235).

Revoking access prevents future authorized API requests but may not by itself delete information previously associated with the application.

## Request deletion

To request deletion of data associated with YouTube Shorts Uploader:

1. Contact the repository owner through the contact options on the [YouTube-Shorts-Uploader GitHub repository](https://github.com/brajjan79/YouTube-Shorts-Uploader) or the owner's linked GitHub profile.
2. State that the request concerns **YouTube Shorts Uploader data deletion**.
3. Provide only the minimum information needed to identify the connected YouTube channel, such as its name or public channel identifier.
4. Do **not** include passwords, access tokens, app secrets, or other credentials.

The owner will use the supplied account details to identify and delete application-associated data under the owner's control, where applicable, and will confirm when the request has been handled. Information controlled by Google and YouTube must be managed through YouTube's own account tools and policies.
