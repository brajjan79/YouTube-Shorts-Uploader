# YouTube Shorts Uploader

YouTube Shorts Uploader is a privately operated content-publishing application used by its owner and authorized administrators. It is not offered as a public software-as-a-service product.

The application connects only to YouTube channels for which access has been authorized. It uses YouTube API Services to upload YouTube Shorts and manage authorized video content.
